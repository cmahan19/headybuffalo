# Site verification: chrome + natural design, concepts, and program foundations

## See it yourself

```bash
npm install
npm run build
npx next start -p 3000          # then open the routes below
```

To see the private admin, add to `.env.local` and rebuild:

```
ADMIN_PASSWORD=choose-a-long-password
ADMIN_SESSION_SECRET=another-long-random-string
ADMIN_INSECURE_COOKIE=1   # only for plain http://localhost
```

## Design system
- **Foundation:** warm bone background, sand/stone surfaces, charcoal ink text.
- **Black chrome:** primary buttons (dark metallic gradient with a fine highlight), the hero, the "How we run the
  shop" band, and the CTA panel; chrome hairline dividers; metallic headline text on dark surfaces.
- **Natural:** sage, moss, olive, and clay; landscape banners; studio pedestals with soft leaf shadows.
- **Color mixed in:** accents only (teal, aqua, yellow, coral, cobalt, berry), in the accent line, card top bars,
  icons, and art glows.
- **Contrast:** `npm run check:contrast` verifies every text/background pair used (all pass WCAG AA), including
  white on moss/clay/olive, chrome text tones on charcoal, and accent text on charcoal.
- Components live in `src/app/components/art/`: HeroBanner, ArtBackground, CollectionBanner, CallToAction,
  UpdatesPanel, EmptyStateGlow, ProductFrame, SectionDivider, LineIcon, ConceptBadge, ConceptProductCard.
